# Muhammad Syed: portfolio

Personal portfolio built with React, TypeScript and Vite. No runtime dependencies beyond React.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check and production build
```

## Edit the content

All text lives in `src/data.ts`: profile, API console responses, projects, experience and stack.
Styles are in `src/index.css`; the interactive API console is `src/components/Console.tsx`.
